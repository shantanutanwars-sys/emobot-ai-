# 🤖 Emobot AI — Friendly Chat Companion

Emobot AI is an intelligent, friendly chat companion designed to provide emotionally aware conversations in a clean, modern web interface.  
It focuses on user engagement, responsiveness, and a smooth conversational experience.

---

## 🌟 What is Emobot AI?
Emobot AI is built to simulate human-like conversations by responding in a warm, friendly, and supportive manner.  
It can be used as:
- A casual chat companion
- A mental wellness support assistant (non-medical)
- A demo project for modern AI-powered web applications

---

## 🚀 Key Features
- 💬 Real-time AI chat interaction
- 🎨 Clean and responsive UI
- ⚡ Fast performance with Vite
- 🔐 Secure environment variables using `.env`
- ☁️ Backend integration with Supabase
- 📱 Mobile-friendly design

---

## 🛠️ Tech Stack
- **Frontend:** React + TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Backend / Auth / DB:** Supabase
- **Package Manager:** npm / bun
